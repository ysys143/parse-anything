Statistical tests

Unless otherwise mentioned, the statistical comparisons were performed using paired t tests (two-tailed, N = 30). To test the reversed feedback effects under conditions of strong sensory evidence, we applied one-sample t tests (one-tailed, N = 27 for S7A Fig, N = 8 for S7B Fig). Repeated t tests on PSEs between data and model (Figs 7B, 7C and S5) were performed (two- tailed, N = 30). Additionally, Wilcoxon signed-rank tests were performed with the same threshold applied (Table D in S1 Appendix). Repeated t tests on each cell of episode frequency maps between the data and the models (Figs 7E, 7F and S6) were performed, and P values were subjected to Bonferroni correction (two-tailed, N = 30; value-updating, P < 0.0000631; world-updating, P < 0.0000633).
